# 4. 치과별 월 현황 + 치과 월 상세 (GPT 질문 4)

## 목록(/work/clinics)
- 상단: 제목 → 월 선택(‹ 2026.11 ›) → 담당자 필터(담당 직원: StaffClinicAccess) → 상태 필터(전체/위험/주의/정상, 마감 상태) → 검색.
- 열: 치과/담당(치과명 + 담당 직원 이름들) | 계약 이행(14/17 · 82% 막대 + 기준 진도선) | 진행 업무(진행 4 · 지연 2) | 원장 요청(미처리 3 · 지연 1: 3일 넘게 처리 안 됨) | 보고/미팅(보고서 n · 미팅 완료/미완) | 월 마감(진행중/운영마감/최종마감=재무점검까지) | 청구/입금(대표만).
- 상태(건강도 대신 3단계 + 사유 문구): 정상 / 주의(기대 진도보다 10%p 이상 부족 또는 지연 업무) / 위험(20%p 이상 부족, 원장 요청 3일 초과, 기한 초과). 행 왼쪽에 상태 색 점 + "위험 · 칼럼 2편 부족 · 요청 1건 지연" 사유.
- 기본 정렬: 전월 미마감 → 기한 초과 → 원장 요청 지연 → 진도 부족 → 정상.
- 아래 접이식 그래프: 최근 6개월 치과별 계약 이행률 추이(LineChart, 진행 중인 달은 점선/구분). 보조: 치과×월 이행률 히트맵 전환.

## 월 상세(/work/clinics/[id]/[month])
- 상단 고정: 치과명 / 2026년 11월 / 담당 직원 / 월 마감 상태 + 요약 4칸(계약 이행 14/17, 업무 8/11, 미처리 요청 3, 보고/미팅).
- 탭: 개요 | 업무 | 발행 | 소통 | 자료 | 정산(대표만).
  - 개요: 좌 60% = 계약 분량(항목별 막대) → 진행 업무 3~5건(기한순) → 원장 요청 / 우 40% = 월 마감 체크리스트(맨 위) → 최근 소통 3건.
  - 업무: 그룹별 업무 표(업무 보드 링크). 발행: 발행 기록 표. 소통: 통화·미팅·요청·특이사항 통합 타임라인(최신순, 유형·날짜·내용·담당·연결 업무; 요청은 상태·기한 표시) + 입력. 자료: 보고서·파일·메모. 정산: 계약금액·청구·입금·재무 마감.
- 월 마감 흐름: 운영 점검(계약 분량 충족 → 보고서 업로드 → 정기 미팅 → 미해결 요청 점검) → 운영 마감(미충족 0건이면 마감, 예외는 사유+승인자 기록 후 이월) → 재무 점검(대표: 청구 → 입금 확인 → 최종 마감). 운영 마감 후 변경은 재오픈 사유 기록. 청구 확인은 운영 마감 조건이 아니라 재무 단계.
- 우선순위: ① 문제 중심 목록 ② 6탭 상세 ③ 운영·재무 분리 마감 ④ 소통 타임라인 ⑤ 6개월 그래프.
