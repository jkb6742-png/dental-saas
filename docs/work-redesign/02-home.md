# 2. 홈(/work/today) (GPT 질문 2)

## 직원 홈 (업무 실행 70%, 정보 30%)
1. 상단 100%: 날짜(11월 12일 목요일), 출근시간·근무 상태, [+ 업무][+ 일정][메모], 퇴근 버튼
2. 요약 100%: 마감 지남 / 오늘 마감 / 내 검토 대기 (숫자 3칸, 클릭 시 해당 목록)
3. 좌 65%: 내가 처리할 업무 6~8건(지연→오늘→이번 주), 체크 완료(검수 필요 업무는 체크 시 '검토 요청'으로 전환), 상태 변경, 상세 열기, "전체 업무 보기 →"
   우 35%: 오늘 일정(시간순) → 내가 담당하는 원장 요청
4. 좌 65%: 담당 치과 월 계약 진행률(가로 막대 + 오늘 기준 기대 진도선)
   우 35%: 내 최근 7일 완료량(세로 막대, 마감 예정과 비교)

## 대표 홈 (운영 위험 60%, 승인·관리 40%)
1. 상단: 출퇴근, 빠른 작업, [전체 업무 | 내 업무] 전환
2. 요약: 지연 업무 / 미배정 / 진행 부족 치과 수 / 미입금 금액
3. 좌 65%: 지금 확인할 운영 문제 5건(치과·문제·담당자·기한·조치 버튼)
   우 35%: 승인 대기(연차·입금 확인·재택 미인증) → 오늘 근무(출근 n·연차 n·미출근 n) → 오늘 일정
4. 좌 65%: 전체 치과 월 계약 진행률 / 우 35%: 업무 상태 분포(누적 막대, 클릭 시 해당 상태 업무)
5. 100%: 직원별 향후 14일 마감 히트맵(X=날짜, Y=직원, 셀=미완료 마감 수)

## 빈 상태
오늘 업무 없음 → "오늘 마감할 업무가 없습니다" + 이번 주 보기 / 일정 없음 → + 일정 추가 /
첫 사용 → 3단계 안내(담당 치과 확인 → 첫 업무 → 일정) / 계약 분량 없음 → 대표에게만 계약 등록 버튼 / 그래프 데이터 부족 → 안내문.
## 갱신: 근태·승인 30~60초, 진행률·그래프 5분, 탭 복귀 시.
