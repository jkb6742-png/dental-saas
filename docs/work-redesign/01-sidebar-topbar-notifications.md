# 1. 사이드바·상단 바·알림 (GPT 질문 1)

## 왼쪽 레일 1단(직원 6 / 대표 7) → 클릭 시 2단 패널(겹쳐 열림, 240px)
| 1단 | 2단 | 직원 | 대표 |
|---|---|---|---|
| 홈 | 내 대시보드(/work/today), 즐겨찾기, 최근 본 항목 | O | O |
| 업무 | 내 업무(/work/tasks?assignee=me), 전체 업무(/work/tasks), 업무 보드(/work/board), 타임라인, 의료광고 검수함(검수 필요·미승인 업무) | O | O |
| 일정 | 통합 달력(/work/calendar), 미팅 일정, 연차 일정, 결제 일정(대표만) | O | O |
| 치과 | 치과 목록·월 현황(/work/clinics), 발행 기록, PMS 자료 | O | O |
| 자료 | 공유 파일(/work/files), 최근 파일 | O | O |
| 사내 | 출퇴근, 연차 신청·내역, 팀 연차 현황 | O | O |
| 경영 | 직원관리, 근태설정, 연차승인, 계약, 청구·입금, 영업 | X | O |
- 2단 패널 아래쪽에 "고정한 치과"(최대 3곳)와 "최근 본 업무"(5개).
- 메신저는 없음.

## 상단 바(52px)
왼쪽 경로 → 가운데 통합 검색(Ctrl+K: 업무·치과·파일·일정 검색 후 바로 이동) → 오른쪽: [+ 빠른 추가](업무·일정·메모·파일) / 근무 상태(출근 09:03·근무 중, 클릭 시 출퇴근) / 알림 종 / 이름(내 정보·알림 설정·로그아웃).
단축키: Ctrl+K 검색, Alt+N 새 업무, Alt+1~7 1단 메뉴, Esc 닫기, ? 단축키 안내.
빠른 추가는 마지막으로 고른 치과·그룹을 기본값으로.

## 알림
| 등급 | 예 | 앱 | 메일 |
|---|---|---|---|
| P0 긴급 | 마감 초과, 검수 반려, 결제일 경과·미입금 | 즉시 | 근무시간 중 미처리 시 재알림 |
| P1 중요 | 검수 요청, 멘션, 오늘 마감, 연차 승인 요청, 결제 D-3 | 즉시 | 하루 요약 |
| P2 일반 | 업무 배정, 담당·일정 변경, PMS 업로드 | 즉시 | 기본 끔 |
| P3 정보 | 업무 완료, 발행 기록, 일반 댓글, 파일 추가 | 수신함만 | 끔 |
- 본인이 한 변경은 본인에게 알리지 않음. 같은 업무의 일반 댓글은 묶음("새 댓글 4개"). 조치 필요한 건 각각.
- 패널: 탭 [전체 | 처리 필요 | 읽지 않음], 날짜 묶음(오늘/어제/이전), 항목에 바로 처리 버튼(업무 열기·검수·연차 승인/반려), 일괄 읽음, 모든 알림 보기.
- 조용한 시간: 평일 19:00~09:00·주말 메일 개별 발송 중지(앱 수신함은 쌓임).
- 하루 요약: 평일 09:10 1회(앱+메일): 오늘 마감·지연·검수 대기·미팅 수 + 우선 확인 3건. 대표는 청구·미입금·연차 승인·월 마감 지연 추가.

## 그래프 위치(참고)
홈 7일 막대 / 업무 전체 상태 누적 막대 / 치과 월 현황 가로 진행 막대 / 경영 월별 청구·입금 추이.
