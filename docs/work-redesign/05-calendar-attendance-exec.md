# 5. 일정·근태·경영 (GPT 질문 5)

## A. 통합 달력(/work/calendar)
- 보기: 월간(기본: 달력 70% + 선택 날짜 상세 30%, 셀당 3개 + "+N") / 주간(월~일 시간표, 미팅 시간·업무 마감) / 사람별(세로 직원 5~10명 × 가로 요일, 업무량·부재).
- 색: 업무 파랑, 미팅 보라, 연차 초록(승인 대기는 연한 점선), 결제 주황(대표만), 연체만 빨강.
- 상세 패널: 담당자·치과·체크리스트·준비물·회의록·연결 업무. 클릭하면 원본(업무·연차·청구) 화면으로.
- 구글 캘린더 연동은 2차(미팅만).

## B. 근태(/work/attendance)
- 직원 '내 근태': KPI 4(이번 달 근무시간 / 연장근무 / 잔여 연차 / 미기록) · 좌 70% 월간 기록 표(날짜·출근·퇴근·실근무·상태) · 우 30% 출퇴근 버튼·연차/반차 신청·추가근무 등록 · 하단 주별 근무시간 막대 + 연차 사용 이력.
- 대표 '팀 근태': 상단(출근 / 휴가 / 미기록 / 52시간 위험 인원) · 중앙 직원별 월간 표(직원·근무일·실근무·연장·지각·미기록·연차 잔여·상태; 직원 클릭 시 일자별 달력) · 우측(연차 승인 대기 / 근태 수정 요청 / 추가근무 승인) · 하단 직원별 주간 근무시간 가로 막대.
- 규칙: 주 40h 정상, 48h 경고, 52h 한도. 추가근무는 기록 필수(날짜·시간·사유, 신청/승인 분리, 실근무 기록 보존).

## C. 경영 대시보드(/work/exec, 대표만)
- KPI(전체 폭): 월 매출(당월 청구 합, VAT 제외) / 당월 입금 / 총 미수금(누적 청구 − 누적 입금) / 30일 내 계약 만료 / 인건비 비율(현재 연봉 합 ÷ 12 ÷ 월 매출).
- 그래프 2열: 최근 6개월 매출·입금 추이(막대+선) / 미수금 경과 기간(30일 이내·31~60·61+).
- 하단: 치과별 수익성 표 70%(월 매출·이행률·추정 원가는 데이터 없으면 "작업시간 기록 후 표시") + 대표 확인 목록 30%(만료 예정 계약, 연체 청구, 영업 제안 진행).
- 권한: 서버·조회 단계에서 대표만. 연봉·청구금액 수정 이력 남김.
