# 3. 업무 보드(/work/board) (GPT 질문 3)

## 표 열(1366px 기준, 카테고리 패널 208px + 나머지 전부)
| 순서 | 열 | 폭 | 표시 |
|---|---|---|---|
| 1 | 선택 | 36 | 체크박스(호버 시 노출, 선택 시 고정) |
| 2 | 업무명 | 가변 최소 360 | 종류 아이콘 + 제목 + 계약 순번(3/8) + 검수·원장요청 작은 아이콘 |
| 3 | 담당 | 76 | 24px 이니셜 아바타, 클릭 시 선택 팝오버 |
| 4 | 상태 | 108 | 색 점 + 텍스트, 클릭 시 팝오버 |
| 5 | 마감 | 112 | 오늘/내일/11.18(수)/2일 지연(빨강), 클릭 시 날짜 선택 |
| 6 | 우선순위 | 56 | 깃발 아이콘(긴급 빨강/보통 회색/낮음 연회색) |
| 7 | 활동 | 72 | 댓글·첨부 아이콘+개수 |
| 8 | 더보기 | 36 | 그룹 이동·복제·삭제 |
- 기본 화면에서 뺄 것: 시작일 열, 종류 열, 그룹 이동 select. 편집할 때만 입력 UI.
- 행 48px, 그룹 헤더 52px. 상세 서랍 440~480px, 표 위에 겹침.

## 보기
표(기본·필수) / 칸반(필수: 할일·자료대기·진행·검토 4열, 완료 접기, 취소 숨김, 카드 드래그로 상태 변경) / 달력(추천: 월·주, 마감 드래그 변경) / 간트(나중).

## 도구 모음(한 줄)
빠른 보기 탭 [전체 | 내 업무 | 지연 | 이번 주 마감 | 검토 대기] + 검색 + 필터(담당 복수·그룹·상태·종류·기간·검수 필요·원장 요청) + 정렬(수동·마감·우선순위·최근 수정). 저장된 보기는 개인용(브라우저 저장).

## 일괄·드래그·체크리스트
- 체크 시 하단 떠 있는 일괄 작업 바: 담당·상태·우선순위·마감·그룹 변경.
- 행 왼쪽 핸들로 같은 그룹 안 순서 이동(정렬이 수동일 때만), 그룹 헤더로 드래그하면 그룹 이동.
- 체크리스트(하위 단계): 업무 상세에서 원고→내부 확인→원장 검수→발행 같은 단계. 표에는 "2/4" 작게.
- 그룹 맨 아래 입력, Enter 저장 후 다음 입력 유지.

## 그룹 헤더
⌄ 그룹명 · 12건 · 완료 7/12 · 지연 2 · 얇은 진행 막대 58% · [+ 업무] [⋯ 메뉴(이름 바꾸기·위/아래·삭제)]. 완료율 = 완료 / (전체 − 취소).

## 카테고리 패널(208px)
상단: 전체 업무, 내 업무, 지연 업무 / 아래: 사내 + 치과(미완료 수, 지연 있으면 빨간 수) / 즐겨찾기 고정·패널 접기.
